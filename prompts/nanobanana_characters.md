# NanoBanana Prompts for Characters

Use these prompts with NanoBanana (or similar AI image generators like Midjourney, DALL-E, Stable Diffusion) to generate the 8 character sprites.

## Style Guidelines
- **Style**: Whimsical, anime, chibi style
- **Format**: Character portrait/sprite, suitable for game use
- **Background**: Transparent or simple colored background (easier to remove)
- **Size**: 512x512 or 1024x1024 (can scale down to 64x64 for sprites)
- **View**: 3/4 view, slightly angled, cute proportions
