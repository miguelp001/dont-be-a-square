# Google Lyria Prompts for Music

Use these prompts with Google Lyria (or similar AI music generators like Suno, Udio, Stable Audio) to create music for the game.

## Music Style Guidelines
- **Genre**: Upbeat J-pop/Chiptune fusion with cute anime vibes
- **Tempo**: 120-140 BPM
- **Instruments**: Synth leads, chiptune drums, cute plucks, electric guitar (for Riff's theme), acoustic elements
- **Mood**: Whimsical, energetic, playful, not too intense
- **Format**: Loop-friendly (30-60 seconds), can loop seamlessly
- **Style**: Retro puzzle game music with modern anime flair

## Track Prompts

### 1. Main Menu Theme
```
Upbeat cute anime chiptune, 128 BPM. Playful melody with bright synth leads, bouncy bassline, and cheerful drum loop. Whimsical and inviting, like a puzzle game menu. J-pop influenced with retro game boy sounds. Loop-friendly, no vocals.
```

### 2. Character Select Theme
```
Sweet and girly anime pop chiptune, 126 BPM. Harp-like plucks, glittery synth arpeggios, gentle percussion with tambourine. Flirtatious and cute without being overly sugary. Friendly character showcase vibe. Instrumental, loopable.
```

### 3. VS CPU Battle Theme
```
Energetic puzzle battle music, 134 BPM. Driving chiptune beat with syncopated drums, catchy hook melody, rising synth stabs. Competitive but cute, with building tension. Mix of 8-bit and modern anime game music. No lyrics, loop-friendly.
```

### 4. VS Player Battle Theme
```
More intense competitive version, 138 BPM. Faster drums, funkier bassline, call-and-response melodies between different synths. Exciting head-to-head match feel with playful energy. Bright and colorful, still cute and whimsical. Instrumental loop.
```

### 5. Online Match Theme
```
High-energy esports-style cute chiptune, 140 BPM. Glitchy effects mixed with bubbly synths, complex drum patterns, electronic leads. Tension and excitement for ranked play. Anime tournament vibes. Fast-paced but not stressful, loopable.
```

### 6. Speed Up / Panic Theme
```
Urgent but playful puzzle music, 142 BPM. Accelerating feel, arpeggiated synths, frantic but cute percussion, rising pitch patterns. Creates pressure without being anxiety-inducing. Short loop that builds excitement. Chiptune anime style.
```

### 7. Victory Theme
```
Triumphant cute j-pop chiptune, 130 BPM. Fanfare-like melody with bells, sparkly arpeggios, celebratory drums. Satisfying victory fanfare, short and sweet (15-20 seconds). Cheerful and rewarding. Loop or one-shot.
```

### 8. Game Over Theme
```
Gentle melancholic but playful chiptune, 110 BPM. Slower tempo with soft synth pads, muted drums, bittersweet melody. Not sad but wistful, like "try again!" energy. Cute game over music with hope for next round. Short loop.
```

## SFX Suggestions
Also consider generating these sound effects:
- Panel swap (click/pop)
- Match/combo (sparkle sounds)
- Chain reactions (rising notes)
- Block raise (mechanical beep)
- Cursor move (soft click)
- Button select (cute blip)

## Tips
- Ask Lyria for "seamless loop" in the prompt
- Export as OGG or MP3
- Keep file sizes reasonable (under 2MB per track)
- Test loops in browser for seamless playback
- Mix in chiptune elements to match the retro puzzle aesthetic
